# Nitro Vibrato Example

## Getting Started

Before building:

1. Download the [IPADIC dictionary](https://github.com/daac-tools/vibrato/releases/download/v0.5.0/ipadic-mecab-2_7_0.tar.xz) and extract.
2. Place `system.dic.zst` into the assets/dictionary folder.

## Building

### Android
```bash
bun run android
```

### iOS
```bash
bun run ios
```

## Running
```bash
bun run start
```
